# SoulX‑Singer 项目全方位研究报告

---

## 1. 项目概览（面向配音导演 & 混音师）

### 1.1 两大核心功能
| 功能 | 简介 | 适用场景 |
|------|------|----------|
| **SVS（歌声合成）** | 给 AI 提供 **参考音色（Prompt）** + **乐谱/旋律（Target）**，让它用这把嗓子重新演唱整首歌。 | 需要精准控制歌词、音高、节奏的专业配音、合成合唱。
| **SVC（歌声转换）** | 直接把 **已有 Demo 人声** 的音色换成 **另一把嗓子（Prompt）**，不需要歌词/乐谱。 | 快速音色迁移、Demo 变声、配音替换。

### 1.2 工作流对比（配音导演视角）
- **SVS**：先准备 **Prompt 音频**（干声），再准备 **Target 歌曲**（带 MIDI/歌词），系统自动转录生成 `metadata.json`，必要时手动校对后合成。
- **SVC**：只准备 **Prompt** + **Target Demo**，系统直接做音频‑对‑音频的换声。

---

## 2. Prompt 选取要点（决定 80% 成果）
| 要素 | 推荐标准 |
|------|-----------|
| **干净程度** | 纯人声、无伴奏、无混响（干声） |
| **时长** | 10‑30 秒（太短信息不足，太长会被截断） |
| **演唱状态** | 稳定段落、无换气、无假声、音量中等（mf） |
| **音域匹配** | 与目标歌曲音域相近（中音区最通用） |
| **录音环境** | 录音棚级别，底噪 < ‑60 dBFS，24 bit WAV |

> **坏 Prompt**：伴奏混合、噪声、假声、极短片段、强效果器。会导致 AI 学到错误的音色特征。

## 3. SVS 使用最佳实践
### 3.1 控制模式选择
| 模式 | 类比 | 何时使用 |
|------|------|----------|
| **旋律控制（melody）** | 跟随 Demo 的 F0 曲线 | 想保留原唱的情感、颤音细节 |
| **乐谱控制（score）** | 按 MIDI 乐谱严格演唱 | 需要音高绝对准确、歌词清晰 |

**推荐**：大多数情况下使用 **乐谱控制**，音高更稳，受 Prompt 质量影响小。

### 3.2 元数据（metadata.json）校正流程
1. **自动转录** → 生成 `metadata.json`（包含 `phoneme`, `note_pitch`, `duration`, `f0` 等）
2. **导出 MIDI** → 在 **MIDI‑Editor**（网页版）逐音符校对：
   - 歌词是否匹配
   - 音符时长是否合理
   - 音高是否跑调
3. **重新导入** → 完成后正式合成。

> 这一步相当于字幕校对，错误的转录会直接导致唱错词或跑音。

### 3.3 参数调节（对应混音台旋钮）
| 参数 | 类比 | 调节建议 |
|------|------|----------|
| **n_steps** | 渲染精度 | 默认 32；交付可提升至 64‑80，渲染时间会增长 |
| **cfg** | 音色执行力度（压缩力度） | 1.5‑3 为安全区；太高会产生“硬压”失真，太低音色漂浮 |
| **seed** | Randomize 按钮 | 固定 Seed 便于对比；换 Seed 可尝试不同随机结果 |
| **auto_shift** | 自动变调 | 大多数情况开启；音域差距大时手动微调半音数 |

## 4. SVC 使用最佳实践
| 注意点 | 说明 |
|--------|------|
| **人声分离** | Prompt/Target 含伴奏时必须打开对应分离选项，分离会略有音质损失，最好提供干声 |
| **自动混合伴奏** | 开启后系统把分离出的伴奏与转换后的人声自动混合，便于快速试听；交付前仍建议在 DAW 手动混音 |
| **长音频分段** | 超过 30 秒时系统自动分段，拼接处可能出现轻微音色跳变，建议手动截取有问题的段落重新生成 |
| **变调** | 与 SVS 同理，auto_shift + 手动 pitch_shift 可微调 |

## 5. 全音域 Prompt 采集方案（30 秒“一气呵成”）
### 5.1 为什么不能直接拼低‑中‑高三段？
- **SVS**：代码只读取 **第一段**（`prompt_meta_list[0]`），后面两段被直接丢弃 → 拼合无效。
- **SVC**：会读取整段 wav，但 Whisper Encoder 关注的是**语义特征**，并非专门学习全音域音色，效果不确定。

### 5.2 可行的“单文件全音域”策略
**目标**：在一次 30 秒录音里让模型“扫描”低‑中‑高三个音区，且不中断。

#### 设计思路
- **连续上行再回落**（像彩虹弧线），避免 VAD 把音频切成多段。
- 使用 **五个核心元音**（啊、哦、衣、我、来）覆盖不同共鸣腔。
- **全程不出现静音 > 0.3 s**，用元音连音自然衔接。

#### 30 秒示例脚本（导演指令）
> 用中等音量，连贯演唱，不停顿。从低到高再回落，像一次呼吸画一个弧。每段可自行编曲，只要保持音高自然上升再下降。

```
[低音区 ~8s]   我——哦——啊——（胸腔低沉）
[上行 ~5s]    来——衣——（音高逐步上升）
[中高区 ~7s]  爱——哦——我——（舒适高音）
[最高点 ~5s]  啊——（保持最高音 1‑2 秒）
[下行回落 ~5s] 哦——来——我——（自然下降回低音区）
```
- **元音解释**：`啊`（全开），`哦`（圆润），`衣`（前腔），`我`（复合），`来`（滑音）帮助模型捕捉不同共鸣。

#### 对 SVS 的变通
因为 SVS 只取第一段，**把最重要的中音区放在最前 12 秒**，后面的上行/下行仍保留供 SVC 使用。

```
[中音区 12s]   （最稳定、最具代表性的句子）
[上行高音 8s]  …
[下行低音 10s] …
```
这样 SVS 能得到可靠的 Prompt，SVC 还能利用全音域信息。

### 5.3 采集要点（配音导演视角）
| 项目 | 标准 |
|------|------|
| **录音环境** | 录音棚、24 bit 44.1/48 kHz WAV、底噪 < ‑60 dBFS |
| **时长** | 30 秒（含前后 0.5 s 余量） |
| **演唱方式** | 稳定、无情绪夸张、避免假声、保持气息连贯 |
| **后处理** | 如有轻微混响可用 **人声分离**（去混响）后再喂模型 |

## 6. 声库建库工作流（完整 15‑20 分钟录制）
> 参考 `vocal_library_workflow.md`（已生成），这里再概括关键步骤。

1. **准备**：录音环境、话筒、无压缩 WAV。\
2. **录制四段**（每段 15‑25 秒）：
   - **A 中音区**（必录）
   - **B 低音区**（必录）
   - **C 高音区**（必录）
   - **D 气声/轻柔**（可选）
3. **自动预处理**：运行项目自带 `preprocess` 脚本生成 `*.wav` + `metadata.json`。
4. **文件组织**：
```
singers/张三/
├─ A_mid.wav
├─ A_mid.json
├─ B_low.wav
├─ B_low.json
├─ C_high.wav
├─ C_high.json
├─ D_soft.wav（可选）
└─ singer_info.txt
```
5. **调用规范**：合成时根据目标曲目音域选择对应 Prompt（表格已在文档中）。
6. **批量合成**：若歌曲音区跨度大，拆段使用不同 Prompt 再在 DAW 中交叉淡化拼接。

## 7. 常见问题速查表
| 现象 | 可能原因 | 解决办法 |
|------|----------|----------|
| **音色不像目标歌手** | Prompt 有混响/伴奏/太短 | 换干净干声、延长至 15‑30 s、去混响 |
| **音高偏高/低** | 音域差距大、auto_shift 不准 | 手动 `pitch_shift` ±N 半音或使用更贴近音域的 Prompt |
| **咬字模糊** | metadata 歌词/时长错误 | 用 MIDI‑Editor 手动校对 `metadata.json` |
| **电音/机械感** | cfg 过高或 n_steps 过低 | 降 cfg 至 1.5‑2，提升 n_steps 至 64‑80 |
| **长歌中段音色跳变** | 自动分段拼接 | 单独截取有问题段落重新生成或手动淡化拼接 |
| **假声歌曲** | 没有假声 Prompt | 额外录制假声段（约 15 s）并在调用时指定该 Prompt |

---

## 8. 总结 & 推荐行动路线
1. **快速实验**（5 分钟）
   - 录 30 秒全音域 Prompt（如上脚本）
   - 用 SVC 直接换声，观察效果。
2. **专业交付**（30 分钟+）
   - 按 **声库建库工作流** 录制 A/B/C（可加 D）
   - 对目标歌曲使用 **乐谱控制** + **metadata 校正**
   - 调参 `cfg`、`n_steps`，固定 `seed`，必要时手动 `pitch_shift`。
3. **后期**：所有生成的干声在 DAW 里进行压缩、均衡、混响等常规混音处理。
