# AI 声库建库流程
### 让每个歌手录一次，支撑所有后续合成

---

## 核心思路：最小采样，最大覆盖

传统采样库要对每个音符、每种力度逐一采样——很贵、很慢。
SoulX-Singer 的 AI 是基于**音色泛化**的，理论上用一段好的参考录音，就能覆盖这个人的全部音域和语种。

**但现实里，一段录音不够——因为：**
- 人在不同音区的音色特征不一样（低音区厚，高音区亮）
- 假声和真声是两套音色
- 轻声和全力声音色差异大

所以，最佳策略是：**每人录 3–5 段，每段覆盖一个音区/唱法区域**，花 15–20 分钟，建立一个小型"提示词包"（Prompt Pack）。

---

## 第一步：录音前的准备

### 录音环境要求

| 项目 | 标准 | 备注 |
|------|------|------|
| 底噪 | < -60 dBFS | 录音棚级别 |
| 混响 | 干声（无房间感） | 贴话筒收音；如有条件用隔音棚 |
| 格式 | WAV，44.1kHz 或 48kHz，24bit | 不要压缩格式 |
| 话筒距离 | 15–20cm | 距离太远会带入空间感 |
| 前处理 | 不加任何效果器（无压缩、无均衡、无混响） | 纯原声 |

---

## 第二步：录音方案——"三区四片段"

每个歌手录以下4个片段，每片段 **15–25 秒**：

---

### 片段 A：中音区主采样（最重要）

**用途**：系统默认使用第一段 Prompt，这段决定整体音色印象

**录制内容**：以中等力度演唱一段歌词，音区在该歌手的自然说话音区稍高一些

**推荐参考曲段（普通话）**：
> 让歌手自由选一首熟悉的中速歌曲，唱副歌前半段，约 16–20 秒。
> 演唱速度不要太快，让每个字能唱满拍。

**注意事项**：
- 力度：mf（中等，不要全力、也不要气声）
- 不要包含表情强烈的处理（哭腔、独特颤音技巧）
- 真声演唱，不要假声混入

---

### 片段 B：低音区采样

**用途**：当目标曲目整体偏低沉时，换用这段 Prompt 效果更好

**录制内容**：在该歌手低音区极限附近约 3–4 个音内稳定演唱

**推荐录制脚本（普通话）**：
> 请用最低但仍然清晰、有力的声音演唱以下内容：
> "山间的溪水缓缓流淌，带走了往日的忧伤"
> 重复 2–3 遍

**注意事项**：
- 不要胸声压迫感太强（声音要稳，不要发抖）
- 放弃追求极低音——在控制良好的低音区录，别强行下探

---

### 片段 C：高音区采样

**用途**：当目标曲目音域偏高时使用

**录制内容**：在该歌手高音区自如演唱的最高音附近

**推荐录制脚本（普通话）**：
> 请用明亮有力的声音演唱以下内容：
> "飞向那遥远的天边，自由自在在云间"
> 重复 2–3 遍

**注意事项**：
- 不要要求挑战极限高音——要稳定的高音，不要破音/漏气
- 男歌手注意真假声交界区，这段尽量找到稳定的高音区录

---

### 片段 D：气声/轻柔采样（可选，有需要时录）

**用途**：当目标曲目需要轻柔、私语感、抒情感时切换

**录制内容**：气息充分、音量很小的演唱

**推荐录制脚本**：
> 请用非常轻柔、像在耳边说悄悄话一样演唱：
> "就这样静静地陪在你身旁，不说话也好"
> 重复 2–3 遍

**注意事项**：
- 这段会有更多气息声，这是正常的
- 嘴离话筒可以稍微远一点（30cm），避免爆音

---

## 第三步：处理流程——建立 Prompt Pack

录音结束后，对 4 段录音跑一遍预处理：

```
对每段录音执行：
1. 如果是干声 → 直接处理（关闭人声分离选项）
2. 如果不确定有无空间感 → 开启人声分离（会做去混响）
3. 系统输出：vocal.wav + metadata.json（含 F0 信息）
```

### 文件命名规范

```
singers/
└── 张三/
    ├── A_mid.wav          ← 中音区 Prompt 原始录音
    ├── A_mid.json         ← 对应的 metadata（自动生成）
    ├── B_low.wav
    ├── B_low.json
    ├── C_high.wav
    ├── C_high.json
    ├── D_soft.wav         ← 可选
    ├── D_soft.json
    └── singer_info.txt    ← 记录音域范围、语种、备注
```

**singer_info.txt 模板**：
```
姓名：张三
性别：男
声部：男中音
自然音域：D2 – A4（MIDI 38 – 69）
假声上限：C5（MIDI 72）
主要语种：普通话、粤语
录音日期：2026-04-03
录音师：XXX
备注：低音区略带沙质感，假声偏弱
```

## 第四步：调用规范——每次合成如何选 Prompt

选 Prompt 的原则：**目标曲目的主要音区落在哪个区，就选哪个 Prompt**。

### 快速判断表

| 目标曲目平均音区 | 推荐用哪个 Prompt | 自动变调建议 |
|-----------------|-------------------|-------------|
| 该歌手中音区 | A_mid | 开启自动变调 |
| 比 A 低 3 个音以上 | B_low | 开启自动变调 |
| 比 A 高 3 个音以上 | C_high | 开启自动变调 |
| 柔情/轻声段落 | D_soft（单独对这段用） | 开启自动变调 |
| 混合音域（副歌高、verse低） | 先用 A_mid 试总体，<br>特别高的段落单独用 C_high 合成再拼 | 视情况 |

---

## 第五步：批量合成策略

一首歌如果有明显的音区段落差异，推荐**拆段处理**：

```
完整歌曲
├── Verse（低）   → 用 B_low 作为 Prompt → 生成 verse.wav
├── Pre-chorus    → 用 A_mid 作为 Prompt → 生成 pre.wav
├── Chorus（高）  → 用 C_high 作为 Prompt → 生成 chorus.wav
└── DAW 里对 3 段做交叉淡化拼接 → 成品
```

这样的好处是每段音色都处在 Prompt 最舒适的音域，音质最稳定。

## 跨语种怎么处理？

SoulX-Singer 支持跨语言合成——Prompt 是普通话录音，Target 可以是粤语或英语歌词。

**但是**：跨语种时 AI 音色保持会略微下降，因为语言的共鸣位置不同。

如果跨语种合成频率高，推荐额外录一套该语种的片段：
- 如果歌手常演唱粤语 → 额外录 A_mid_cantonese.wav
- 英文歌手 → A_mid_english.wav

**录音脚本（粤语版片段 A）**：
> 请用正常音量演唱以下粤语歌词（可选已熟悉的歌曲段落）：
> 约 15–20 秒，中音区，中等力度

## 常见问题

**Q：录完后 AI 合成出来的不像这个人怎么办？**
→ 检查录音是否有混响残留，如有重新做去混响处理
→ 确认选的 Prompt 片段里没有气声/假声混入
→ 调高 cfg 系数（试试 3–4）

**Q：合成出来的音高偏高/偏低？**
→ 检查选用的 Prompt 音区是否和目标曲主音区匹配
→ 手动指定变调半音数做微调

**Q：同一首歌里有人感觉音色"换"了？**
→ 这是因为用了多段不同 Prompt 拼接，需要在 DAW 里做长一点的交叉淡化（建议 0.5–1秒）

**Q：假声唱法的歌曲如何处理？**
→ 需要单独录一段假声 Prompt（片段 E，假声区演唱 15 秒）
→ 系统会直接捕捉假声音色
→ 目前 SoulX-Singer 对真假声切换处理有限，假声歌曲建议整段用假声 Prompt

**Q：后期工作在哪里做？**
→ SoulX-Singer 输出的是干声，所有效果器（压缩、均衡、混响、效果）都在 DAW 里正常处理
→ 合成声整体底噪很低，正常当干声对待即可

## 总结：每个歌手的最小录音清单

| 片段 | 时长 | 内容 | 是否必录 |
|------|------|------|----------|
| A 中音区 | 20s | 中等音量，自然演唱 | ✅ 必录 |
| B 低音区 | 15s | 稳定低音区，避免嘶吼感 | ✅ 必录 |
| C 高音区 | 15s | 稳定高音区，避免破音 | ✅ 必录 |
| D 气声轻唱 | 15s | 轻柔演唱，带气声 | 🔲 视需求 |
| E 假声区 | 15s | 纯假声演唱 | 🔲 视需求 |

**总录音时间：15–20 分钟/人（含调整）**
**预处理时间：约 5–10 分钟/人（自动运行）**
**成果：一个可复用的 Prompt Pack，支撑该歌手的所有后续合成任务**
