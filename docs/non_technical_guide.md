# SoulX-Singer 使用指南
### 写给配音导演与混音师

---

## 这个工具能做什么？

SoulX-Singer 本质上是一个 **AI 歌手**，它能做两件事：

---

### 功能一：「换声合唱」—— 歌声合成（SVS）

> **类比**：给 AI 听一段"参考声音"，然后让它按你提供的乐谱 and 歌词，用那把声音重新唱一遍。

**你需要准备：**
1. **Prompt 音频**（参考音色）——你想要合成出来的那把嗓子的录音
2. **Target 歌曲**——包含完整乐谱信息（歌词 + 音符）的那首歌

系统先"听"清楚参考音色是什么人、什么风格，再对照乐谱，用这把声音把歌唱出来。

---

### 功能二：「音色替换」—— 歌声转换（SVC）

> **类比**：已经有一条录好的 Demo 人声轨，想把它换成另一个人的嗓子，但旋律、节奏、咬字全部保留。

**你需要准备：**
1. **Prompt 音频**（参考音色）——你想换成的那把嗓子的录音
2. **Target 音频**——已录好的那条 Demo 人声

系统直接把 Demo 的"唱法骨架"保留，把音色外皮换掉。**不需要歌词和乐谱**，直接音频对音频。

---

## 最关键的事：Prompt 音频怎么选？

Prompt 音频的质量，**决定了 80% 的最终效果**。可以把它理解成"母带参考"——垃圾进，垃圾出。

### ✅ 好的 Prompt 长这样

| 要素 | 标准 |
|------|------|
| **干净程度** | 纯人声，无伴奏，无混响（干声最理想） |
| **时长** | 10–30 秒；太短音色信息不够，超过 30 秒会被截断 |
| **演唱状态** | 稳定演唱段落；避免换气、假声、跑调的部分 |
| **音域** | 尽量选与目标歌曲音域相近的段落（如目标曲是中低音区，Prompt 也选中低音段） |
| **录音环境** | 录音棚级别优先；条件允许就先做降噪/去混响处理 |

### ❌ 会出问题的 Prompt

- 混音成品（带了伴奏、效果器全开）→ 音色提取失败，开启"人声分离"会损失细节
- 只有几秒的短片段 → 音色个性不明显，容易"平均化"
- 假声段落 → AI 会认为这把嗓子的音色就是假声，转换后产生偏差
- 环境录音/手机录音 → 噪底会被一起学习进去

## 歌声合成（SVS）怎么用效果最好？

### 第一步：选好控制方式

系统提供两种"指挥 AI 唱歌"的方式，相当于给歌手不同类型的谱子：

| 方式 | 类比 | 适合场景 |
|------|------|----------|
| **旋律控制（melody）** | 录了一版 Demo，AI 跟着这版 Demo 的音高曲线唱 | 想保留原唱的情感和颤音细节 |
| **乐谱控制（score）** | 给一份 MIDI 乐谱，AI 按乐谱的音符唱 | 需要音高绝对准确、字迹清晰 |

> 💡 **推荐用"乐谱控制"**——音高更稳定，不受 Demo 录音质量影响。

### 第二步：检查 / 修正乐谱数据（关键！）

系统会自动转录歌词和音符，但自动识别难免出错，**就像 AI 字幕时常会出错一样**。

错误的转录 = 唱错词 + 音高乱跑。

**推荐工作流**（类似字幕校对）：

```
自动转录 → 导出 MIDI 文件 → 在网页 MIDI 编辑器里人工逐音符校对
→ 保存 → 重新导入 → 开始合成
```

校对时主要看：
- 歌词有没有识别错
- 每个字的音符时长对不对（太长或太短都会影响咬字）
- 音高有没有跑到错误的八度

> 🔗 MIDI编辑器地址：[SoulX-Singer-Midi-Editor（网页版）](https://huggingface.co/spaces/Soul-AILab/SoulX-Singer-Midi-Editor)

## 歌声转换（SVC）怎么用效果最好？

SVC 相对简单——直接"音频换皮"，不需要字幕/乐谱数据。

### 主要注意事项

**关于人声分离：**
- Prompt 音频带伴奏 → 务必开启「Prompt 人声分离」
- Target 音频带伴奏 → 务必开启「Target 人声分离」（默认已开启）
- 分离过程会损失一点音质，**条件允许请给纯人声**

**关于伴奏混合（SVC 特有）：**
- 开启「自动混合伴奏」后，系统会把分离出来的伴奏和转换后的人声自动混在一起
- 方便直接听成品感，但不代表混音精度达到制作标准
- 最终送审/交片请用 DAW 手动做混音

**关于长歌曲（超过 30 秒）：**
- 全曲转换时，系统会自动分段处理，拼接处可能出现轻微音色波动
- 如果你对某一段不满意，可以把那一段单独截出来重转

---

## 音调（变调）相关

当 Prompt 和 Target 的音域差距比较大（比如一个男中音 Prompt，一个高音 Target 歌曲），需要变调处理：

| 选项 | 含义 | 建议 |
|------|------|------|
| **自动变调（开启）** | 系统自动计算两者音高中心差值并偏移 | 大多数情况够用，先试这个 |
| **手动变调（±N 半音）** | 自己指定升/降多少个半音 | 自动变调跑偏时使用；正数升调，负数降调 |

> 注意：指定了手动变调数值（非0）后，自动变调会自动失效。

---

## 参数旋钮怎么调？

可以把这两个参数理解成混音时的旋钮：

### 采样步数（n_step）
- 类比：**渲染精度**
- 默认 32 步；数值越大，细节越丰富，但等待时间越长
- 做预览：保持 32；做交付：可以试试 64–80

### 引导系数（cfg）
- 类比：**AI 对 Prompt 音色的"执行力度"**
- 数值越大，和 Prompt 音色越像，但会更"用力"，容易产生失真感（有点像压缩过头）
- **建议范围：1.5–3**；默认是 3（SVS）和 1（SVC）
- 遇到电音/失真感 → 往小调；遇到音色飘 → 往大调

### 种子（Seed）
- 类比：**Randomize 按钮**
- 固定数字 = 每次生成结果一致（方便对比参数差异）
- 换个数字 = 重新随机，有时候换一个 Seed 就能显著改善结果

## 常见问题速查

| 现象 | 最可能的原因 | 处理方向 |
|------|-------------|----------|
| 听不出是那把嗓子 | Prompt 音频有混响/伴奏/太短 | 换更干净的 Prompt，或先做降噪 |
| 音高偏高/偏低 | 音域差距大，自动变调不够准 | 手动设置变调半音数 |
| 咬字模糊不清 | 歌词/音符时长转录有误 | 用 Midi-Editor 校对 target 元数据 |
| 有电音/机械感 | cfg 系数太高 / 步数太少 | 把 cfg 降到 1.5–2，步数增加到 64 |
| 长歌中段有音色跳变 | 分段拼接问题 | 把有问题的段落单独截取重转 |
| 每次结果差异很大 | Seed 是随机的 | 固定一个 Seed 值后再调参 |

---

## 推荐工作流汇总

### 快速出样（SVC，5分钟）
```
1. 准备好 Prompt 干声（10–20秒）
2. 上传 Target 音频（允许带伴奏，开启分离选项）
3. 开启「自动变调」+「自动混合伴奏」
4. 点击生成，试听
5. 不满意？换 Seed 或微调 cfg，再试一次
```

### 精品交付（SVS，需要投入时间）
```
1. 准备高质量 Prompt 干声
2. 上传 Target 音频，运行自动转录
3. 导出 MIDI → 在 Midi-Editor 里逐字校对歌词和音符
4. 把校正后的 MIDI 导回
5. 选择「乐谱控制」模式，生成
6. 觉得音色不够像？提高 cfg（不超过4）
7. 觉得有失真？降低 cfg，增加步数
8. 导出干声，在 DAW 里正常做混音
```
